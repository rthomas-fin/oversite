OverSite privacy

Updated October 28, 2026

OverSite Financial Command Center is a private workspace for its owner to organize receivables, bills, cash plans and documents. It connects the website to the owner's Google Sheets and Google Drive workspace.

Information the app uses

Google sign-in supplies the account email and authorization needed for the connection. The app reads and updates financial records in the connected Sheet. It reads files and metadata in registered Drive folders, saves uploads and form drafts, and uses Google document conversion or OCR to process supported files. Records can include invoices, statements, company details, contact information and a reference to a saved signature image. The app does not apply signatures automatically.

How information is used

Information is used to display the workspace, calculate cash forecasts, identify document fields, match statements to invoices, update eligible ledger records, prepare form drafts and show processing results. Background checks can continue under the owner's Google authorization while the website is closed.

The app does not sell Google user data, use it for advertising or send it to an external AI service. Google API data is used only to provide these workspace features, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Where information is stored

Shared financial records, uploaded originals and saved drafts stay in the connected Google services and are loaded into the authorized browser. The GitHub Pages website serves interface files; private workspace records and uploaded documents are not included in its public code.

A short-lived Google access token and private planning scenarios can be retained in the browser tab's session storage. Refreshing the page does not extend the token's expiry. Sign out clears the saved token. Document-notification acknowledgements use local browser storage containing record keys, not document contents. Downloads and exported backups are saved wherever the user chooses.

Google provides sign-in, file storage, document processing and the app's backend. GitHub provides website hosting. These providers may process connection and service logs under their own policies: Google Privacy Policy and GitHub General Privacy Statement.

Access, retention and deletion

The current workspace backend restricts access to its configured owner. Files and records remain until the owner changes or deletes them in the connected Google services. Archiving a review hides that review; it does not delete the original document or all retained history. Google version history, trash and backups follow the owner's Google settings and the provider's retention practices.

The owner can revoke the app's Google access in Google Account connections. Revocation stops authorized access but does not delete documents already saved in Drive or records in Sheets. Local browser data and downloaded exports can be cleared separately.
